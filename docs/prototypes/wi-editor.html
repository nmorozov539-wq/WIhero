WI Hero, phone first

A working sketch of what opens when you tap the book icon in SillyTavern. We fill it in screen by screen. Everything here uses example books.

Try

  • Pull the tab row left past its end. A ghost tab appears; let go once it says "Release" to open a new tab, or slide back to cancel.
  • Long-press a book or entry to open it in a new tab. The ⋯ on each row does the same.
  • ⌄ at the left edge opens view options for this screen (list or tiles, sort, disabled entries) and tab actions.
  • Home tab (house icon) is always Home: opening a book from it opens a new tab next to it.
  • Back under the phone acts like Android's Back button.

Agreed so far

  • Tabs run along the top and scroll sideways, like MiXplorer.
  • New tab: pull the row past its end. A new tab starts at Home.
  • Home lists books and folders of books, as a list or as tiles.
  • Search lives in the bottom bar and opens as an overlay. It is universal: books, folders and entries from everywhere, grouped, with the current book's entries first. No commands. Hidden in the entry editor.
  • Long press opens something in a new tab.
  • Top row: ⌄ menu, then the Home tab (icon only, can't be closed), then the scrolling tabs. No tab list; you scroll.
  • ⌄ menu holds view options for the current screen plus tab actions, like MiXplorer's. More can move in later if needed.
  • Bottom bar keeps only frequent actions: Search, + New, Select.
  • Home tab never leaves Home. Anything opened from it gets its own tab beside it.
  • Back on a tab's first screen closes that tab and lands on Home, instead of turning it into a second Home.
  • WI settings (ST's global ones) sit behind ⋮ on Home.

Proposed in this sketch

  • × only on the active tab, so tabs stay narrow and you can't close one by accident while scrolling.
  • Back steps back inside the current tab. On a tab's first screen it would close the editor.
  • Active badges on each book: Global, Character, Chat, or off.
  • Select is a bottom-bar button, since long press is taken.

Entry page (draft 1)

  • Try: Eldoria → The Capital (has a condition), Moon Cult (vectorized), Seraphina → Seraphina (permanent).
  • Top: ← on the left goes up to the book (Android's standard spot for it). The right bubble holds the entries drawer, reading/editing and ⋮ (duplicate, move, copy, delete).
  • Title is edited in place. The book line under it is just information.
  • On/off switch sits at the end of the strategy line; an off entry dims.
  • Strategy is a thin line; tap to change. Under it, a one-line keyword box: type a comma-separated list, it scrolls sideways. In reading mode the keywords show as bubbles.
  • Permanent hides the keyword box (ST ignores keywords). Vectorized keeps it, since ST still matches keywords for vectorized entries.
  • + Add condition adds ST's secondary keywords: a thin line ("And any of / And all of / But none of / But not all of these") over a second keyword box. ST allows one per entry.
  • Content is the page itself, Obsidian-style: a heading, then borderless text with a dim "Type here".
  • Parameters stay folded, with a summary of whatever isn't default (try changing Probability). Depth and Role only appear for "At depth".
  • No bottom bar here; the keyboard needs the space. Back or the book line leaves.
  • WI Hero story settings have a reserved spot at the end of Parameters, filled in later.

Book page (draft 1)

  • Name ▾ opens the view switch: List or Story (node editor). No Classic fallback: WI Hero replaces ST's drawer outright; turning the extension off brings ST's back. ⋮ has rename, duplicate, move, export, delete.
  • Global chip toggles whether the book is active globally (green) or not (gray).
  • Linked chip shows the first link and a count ("Seraphina +2"); long names cut off. Tap it to see every character and chat link, unlink, or link this chat. No master switch; unlinking is how you turn a linked book off.
  • New entry defaults is the folded section at the top. ST books have no settings of their own, so this holds what new entries start with (stored by WI Hero).
  • Entry rows carry a colored stripe: green keywords, blue permanent, purple vectorized, gray when off. No parameters.
  • Group by lives in ⌄: nothing, strategy, or your own folders (WI Hero's entry folders, collapsible).

Selection, + and folders

  • Select swaps the header for ✕ · count · All/None · Invert · Delete (with Undo), and the bottom bar for Move · On · Off · Edit….
  • Folder headers get a checkbox too: ticking it selects every entry inside (unticking clears them).
  • Move lists folders, "No folder" (take out) and "+ New folder". That's the main way folders get made: from entries you already picked.
  • Edit… is bulk parameters: same rows as an entry, "Mixed" where they differ, and only what you change is applied.
  • + opens a new entry's page with the name ready to type. Leave it empty and it's discarded. Each folder header has its own + to create inside it.
  • Empty folders come from "New folder…" in the book's ⋮.

Home: books

  • + asks for a name, then opens the new book in its own tab.
  • Book folders work like entry folders: Select → Move → "+ New folder", or Move from a book's ⋯.
  • Deleting books or entries never asks; an Undo toast appears instead. For books, the file is only removed once the toast is gone.
  • WI settings (⋮) show the three most used first (Budget, Scan depth, Recursive scan); everything else is behind "More settings".
